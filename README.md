## Sales Dashboard — Retail User Behavior Analysis

SQL analysis of a ~100k-row retail user behavior dataset (Kaggle), exploring session activity, revenue, and conversion patterns to support business decision-making.

Key questions answered:
- What is the overall conversion rate across all sessions?
- Which product categories generate the most revenue?
- How do daily session volumes trend over time?
- Which channel (app, mobile, web) converts best?

Key finding: The app channel converts at 4.44%, ~28% higher than web (3.47%) — suggesting marketing/UX investment may be better placed toward the app experience.

Tools: SQLite (SQL), sqliteonline.com
Skills demonstrated: aggregation, conditional aggregation (CASE WHEN), GROUP BY, date extraction, query optimization for readability
